# Educational content standards

This folder defines the minimum requirements for content to be treated as **educationally validated** in engleza.wiki.

These standards apply to newly authored or materially revised learning and assessment content. Existing seeded/demo content is not retrospectively approved by these documents and must not be represented as validated merely because it passes an automated audit.

## What “educationally validated” means

Content may be labelled educationally validated only when all applicable gates below are satisfied:

1. **Instructional purpose:** the learning or assessment objective is explicit and appropriate for the intended learner.
2. **Educational correctness:** language, answers, explanations and level assignment have been checked by qualified reviewers.
3. **Construct and level fit:** the content measures or teaches what it claims to measure or teach, at the intended CEFR level or curriculum stage.
4. **Usability and accessibility:** learners can understand and complete it without accidental ambiguity or interface barriers.
5. **Evidence and traceability:** authorship, sources, review decisions, versions and any pilot evidence are recorded.
6. **Release approval:** the required reviews are complete, blocking issues are resolved and the exact version being released is approved.

Automated checks are necessary for consistency and completeness, but they cannot establish educational correctness, CEFR validity or suitability for learners.

## Status vocabulary

Use explicit statuses and do not blur them:

- **Draft:** authored, not yet reviewed.
- **In review:** submitted for educational review; approval is pending.
- **Teacher-reviewed:** the required teacher review is recorded for this exact version.
- **Pilot-tested:** learner pilot evidence is recorded; this does not automatically mean validated.
- **Educationally validated:** every applicable review, evidence and release gate is satisfied.
- **Retired:** withdrawn from new use; historical attempts remain unchanged.

A status must never be inferred from the existence of content, a passing code test, a generated explanation or an automated audit result.

## Scope and claims

The current placement assessments sample grammar, vocabulary and reading only. They do not measure listening, speaking or writing. Until an appropriate validation study supports stronger claims, learner-facing results must remain indicative estimates and must not be described as official CEFR certification or a complete measure of English proficiency.

## Change control

Any material change to a prompt, options, answer key, explanation, CEFR level, skill, source text, scoring rule or form composition invalidates the previous approval for the changed content. Re-review the changed version and preserve the prior version and its review history.

Use the most specific standard file above as the acceptance checklist for each content type. When a content item spans several types, all applicable standards apply.
